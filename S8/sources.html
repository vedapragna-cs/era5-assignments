Where every date comes from

The assignment says the chronology is the part that is easiest to get wrong and easiest to check. So here is all of it, checkable.

The convention

The sort key is the arXiv v1 submission date — the day the idea became public, not the conference publication date and not the day it became popular. Two mechanisms that share a paper share a date, and that is not an error: standard attention and sinusoidal encoding are both Attention Is All You Need, 2017-06-12.

Shipped means one thing throughout: the first public release of weights or reference code implementing the mechanism, read from the GitHub or HuggingFace API where possible. Rows marked * are documented releases we could not read from an API. An earlier version of this site mixed third-party adoption with authors' own releases in this column; that was wrong and is documented as a retraction.

How to re-run the check yourself

python3 verify_dates.py     # re-fetch every arXiv v1 date, diff, exit 1 on drift
python3 analyse.py          # recompute every number on the findings page
python3 build.py            # validate all cards, regenerate these pages

Last run: 31 of 34 dates re-verified against the arXiv API, 3 with no paper by design, 0 failures (2026-08-21T23:12:54Z). The raw API response is committed at data/arxiv-response.xml so the check also runs offline.
